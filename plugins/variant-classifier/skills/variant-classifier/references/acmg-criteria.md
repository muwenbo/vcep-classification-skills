## Point-Based Classification

| Classification | Point Range |
|----------------|-------------|
| Pathogenic | >= 10 |
| Likely Pathogenic | 6-9 |
| VUS | -5 to +5 |
| Likely Benign | -6 to -9 |
| Benign | <= -10 or BA1 |

Points: Very Strong = 8, Strong = 4, Moderate = 2, Supporting = 1
